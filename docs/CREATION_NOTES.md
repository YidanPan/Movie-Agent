# 创作说明模板

将以下内容替换为实际演示结果后，用于比赛提交页。

## 作品名称

Movie-Agent：一句话科幻创意到短片制作计划。

## 创作动机

短片创作常在剧本、分镜、视觉设定之间反复断裂。本项目将这些工作拆分为可协作的 Agent，并以项目 JSON 保存每一次创作决策，方便恢复、审阅和后续视频生成。

## Agent 分工

- 导演 Agent：主题、叙事边界和合规约束。
- 编剧 Agent：短剧本、旁白、节奏。
- 视觉设定 Agent：角色、场景、风格和声音规范。
- 分镜 Agent：生成 6–10 个可独立生成的 4–8 秒镜头。
- 质检 Agent：结构、时长、提示词和版权风险检查。
- 生成 / 剪辑 Agent：当前保留 mock 流程，后续接入 Spark ComfyUI 与 FFmpeg。

## 复现方式

1. 在创空间配置 ModelScope API Secret。
2. 打开应用，输入原创科幻创意、时长和风格。
3. 查看分镜与质量日志；可恢复项目、重新规划单个镜头、导出制作计划。
